# Accessibility checklist

- [x] Every control has a visible, programmatically associated label.
- [x] Semantic navigation, main, section, aside, heading and footer landmarks.
- [x] Keyboard focus is visible; controls are native and keyboard-operable.
- [x] Status uses a polite live region; form errors are readable text.
- [x] Responsive viewport metadata and a mobile breakpoint.
- [x] Summary values use text content and cannot inject submitted markup.
